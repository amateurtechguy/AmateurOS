# AmateurOS
AmateurOS is an OS based off of Edex UI's theme. Has anyone watched Mr.Robot and wanted to have this cool operating system that just makes you feel like him? well AmateurOs is the operating system for you, it combines the whole Mr.Robot vibes with the amateur tech guy's theme, which would explain the whole red and black color scheme.

Click [here](https://amateurtechguy.github.io/AmateurOS/) to try the website out!


⚠️DISCLAIMER: all backgrounds used are from google images, I did NOT make them!⚠️
